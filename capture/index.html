처음 사용하나요? Mac에서 실행 파일을 켜 주세요.
  1. Mac 실행 파일 다운로드 후 압축을 풀어 주세요.
  2. Start-Capture.command를 실행하세요. 처음에는 필요한 프로그램을 준비합니다.
  3. 자동으로 열린 페이지에서 URL을 입력하고 캡처하세요.

캡처하는 동안 Mac과 터미널 창을 켜 두세요. 브라우저가 로컬 네트워크 접근을 물으면 허용해 주세요.

연결이 안 되면 내 Mac에서 캡처 화면 열기 ↗

Node.js가 없다면 공식 사이트의 LTS 버전을 한 번 설치해 주세요. 실행 권한 오류가 나면 터미널에서 bash 를 입력하고 실행 파일을 끌어다 놓은 뒤 Enter를 누르세요.

# Capture

URL → PC 1080px / 모바일 720px 전체 페이지 PNG.

사용 주소: https://8lee8lee.github.io/capture/

## Mac에서 사용

1. 페이지의 **Mac 실행 파일 다운로드**를 누르고 압축을 풉니다.
2. `Start-Capture.command`를 실행합니다. Node.js 22 이상이 없다면 공식 사이트의 LTS 버전을 먼저 설치합니다.
3. 자동으로 열린 페이지에 URL을 넣고 **전체 페이지 캡처**를 누릅니다.
4. PC·모바일 PNG를 각각 다운로드합니다.

실행 권한 오류가 나면 터미널에 `bash `를 입력하고 실행 파일을 끌어다 놓은 뒤 Enter를 누릅니다. Mac 보안 확인이 필요한 경우 시스템 설정의 안내를 따릅니다.

캡처 중에는 Mac과 터미널 창을 켜 둡니다. 종료는 터미널에서 Ctrl+C.
GitHub 화면에서 로컬 엔진 연결이 안 되면 http://127.0.0.1:4318/ 을 엽니다.
브라우저가 로컬 네트워크 접근을 물으면 허용합니다.

## 동작

- 데스크톱: 화면 폭 1080 CSS px, 출력 폭 1080px.
- 모바일: 화면 폭 360 CSS px, 2배 해상도, 출력 폭 720px.
- 전체 스크롤 후 이미지·폰트 로딩을 기다립니다.
- 팝업 자동 닫기는 알려진 닫기·거부 버튼을 사용합니다. 모든 사이트에 보장되지는 않습니다.
- 자동 닫기를 끄면 페이지에 보이는 팝업을 포함합니다.
- 로그인·보안 인증, 무한 스크롤, 50,000px를 넘는 이미지는 지원하지 않습니다.
- 일반 브라우저의 로그인 상태를 가져오지 않습니다.
- 결과는 Mac 임시 폴더에 보관하며, 다음 촬영 또는 정상 종료 시 삭제합니다. GitHub에 업로드하지 않습니다.

## 파일

`index.html`: 입력 화면. `engine/server.cjs`: 로컬 연결. `engine/capture.cjs`: 촬영.
의존성은 Playwright 하나입니다. `capture-engine.zip`은 이 파일들과 Mac 실행 파일을 묶은 설치 패키지입니다.
